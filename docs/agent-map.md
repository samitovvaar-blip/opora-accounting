# Карта ИИ-сотрудников ОПОРА Бухгалтерии

## Общий цикл работы

Каждый сотрудник работает одинаково: получает данные из 1С и внешних источников, строит контрольные точки периода, формирует очередь исключений, объясняет решение и передаёт бухгалтеру только действие, которое требует подтверждения.

## Заместитель главного бухгалтера

Главная страница не заменяет ОСВ. Она собирает из неё статусы агентов, приоритетные исключения, готовность периода и общую очередь задач.

## Нейла — банк и касса

- Счета: 50, 51.
- Источники: поступления и списания с расчётного счёта, ПКО и РКО 1С; банковская выписка; в будущем — API банка и Мой ОФД как сверочный источник.
- Контроль: полнота документов, статья движения, назначение, контрагент, совпадение выписки с 1С, помесячные обороты и остатки.
- Результат: очередь расхождений и согласованные черновики документов.
- Ограничение: Нейла не проводит и не меняет проведённые документы без подтверждения.

## Марта — первичные документы

- Счета для контроля: 19, 41, 60, 62 (уточняются по учётной политике компании).
- Источники: поступления, реализации, УПД, акты, счета и договоры в 1С.
- Контроль: документ без основания, НДС и реквизиты, закрывающий документ, соответствие документу банка/кассы.
- Результат: очередь «дозапросить / сопоставить / подготовить черновик».

## Лев — взаиморасчёты

- Счета для контроля: 60, 62, 71, 76 (уточняются по учётной политике компании).
- Источники: обороты и сальдо по контрагентам, договоры, документы расчётов.
- Контроль: просрочка, авансы, отрицательное сальдо, неразнесённые платежи, расхождение с актом сверки.
- Результат: список рисков по контрагентам и проект акта сверки.

## Рита — отчётность

- Счета и регистры: определяются по системе налогообложения и календарю отчётности.
- Источники: ОСВ, регламентированные отчёты, контрольные соотношения, статусы сдачи.
- Контроль: закрытие периода, контрольные соотношения, дедлайны, ошибки перед сдачей.
- Результат: чек-лист готовности отчётности и очередь исправлений.

## Что утверждается до запуска нового агента

1. Компания, организации и период контроля.
2. Точный перечень счетов и регистров из ОСВ.
3. Контрольные точки и допустимые отклонения.
4. Какие черновики агент вправе подготовить.
5. Какие действия всегда требуют подтверждения главбуха.
